기능목록 

1. 입력 기능 
- (1) 구매 상품명, 수량 입력 기능 
- (2) 멤버십 할인 여부 입력 기능 
- (3) 프로모션 위한 필수 수량 추가 여부 입력 기능 
- (4) 프로모션 미적용시 구매 여부 입력 기능 
- (*) 추가 구매 여부 입력 기능 

2. 출력 
- 영수증 출력 

3. 재고 관리 
- 재고 수량 업데이트 기능 
- 결제 가능 여부 확인 기능 

4. 프로모션 
- 프로모션 적용 여부 확인 기능 

5. 멤버십 할인 
- 프로모션이 있는 경우 - 남은 금액의 30% 할인 적용 기능 
- 프로모션이 없는 경우 - 금액의 30% 할인 적용 기능 
- 한도(8000원) 넘어갈 시 처리 기능

6. 예외 처리 및 재귀
- 입력 (1) error: 잘못 입력시, 다시 입력 기능 
- 입력 (1) error: 재고 없을 시, 다시 입력 기능 
- 입력 (2),(3),(4) error, 다시 입력 기능
- 입력 (*) 다시 입력 기능 
- 띄어쓰기는 무시한다. 
  - 오렌지 주스 == 오렌지주스 
  - [사이다-2],[감자칩-1] ==  [사이다- 2 ],[감자칩- 1 ]
